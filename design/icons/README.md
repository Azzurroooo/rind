# Rind PNG exports

All sizes use the shared green mark with transparent outer corners:

| File | Size |
| --- | --- |
| `rind-16.png` | 16 × 16 |
| `rind-32.png` | 32 × 32 |
| `rind-48.png` | 48 × 48 |
| `rind-192.png` | 192 × 192 |
| `rind-512.png` | 512 × 512 |

The [SVG master](../../assets/rind.svg) scales to any size; [the animated SVG](../../assets/rind-animated.svg) uses the same geometry. See [the shared preview](../rind-logo.html) and [regeneration instructions](../README.md). The previous amber/cyan variants are superseded.
