# 其他用户能力 U24–U29

遵循 [公共执行与清理规则](README.md)。每项单独请求、执行和判定；未具备对应模型能力或入口则记 BLOCKED，不默认购买服务或开启外部通信。

| ID / 消耗 | 前置与操作流程 | 通过标准和证据 |
| --- | --- | --- |
| U24：Skill 真正生效 / 少量 | 在测试工作区 `.rind/skills/acceptance-report/SKILL.md` 按现有格式定义技能，要求生成特定字段和唯一标记的报告。先 `/skill` 确认发现，再通过该技能支持的显式调用入口请求报告，不在任务中重复技能正文。另用普通语言描述匹配职责的任务检查自动选择。 | 列表与实际可用技能一致；调用记录和模型请求证明正文已加载；报告满足字段/标记要求。显式调用与自动选择分别判定，不能仅凭列出名称算激活成功。证据为 SKILL.md、调用、请求、产物；全部随测试目录清除。 |
| U25：/init 与已有文档 / 少量 | 在合成小项目执行 `/init project`，检查生成内容；将文档改成带自定义规则的版本，再次 init，按当前提示处理；另在隔离 home 验收 `/init user`。 | 生成位置正确，内容匹配项目而非虚构；已有规则不会在无明确操作的情况下被静默丢弃；下一轮文档实际进入上下文。保留提示、文件前后差异及请求摘要；不能写到真实用户 home。 |
| U26：登录、退出与凭据来源 / 少量 | 隔离 home 与环境，只给本次测试指定的 provider 凭据来源。先验证未配置时的反馈，再 `/login`、普通对话、退出重开、`/logout`、再次发消息。环境变量/workspace 凭据回退作为单独分支测试。 | 登录后能请求正确模型，重开可用；logout 删除对应存储凭据，若另有配置来源，应准确显示并遵循其优先级，不能误判为退出失败；错误、日志和 UI 不显示密钥。结束后清除测试凭据与登录临时资源；不注销用户原有账号。 |
| U27：后台 shell 与输出 / 多轮 | 在临时工作区要求启动一个定时输出标记的后台任务，使用当前任务监视器/后台查询入口查看它，等待另一轮普通对话后再次查看并停止；重复一次运行中退出 rind。 | shell 后台任务跨空闲轮次仍可查询，输出归属正确且不污染输入；停止/退出后本次子进程不继续运行，文件不持续增长。验证实际 PID、输出、任务状态和端口；不能只观察 UI 显示已停止。 |
| U28：图片等多模态输入 / 依模型 | 用合成图片写入随机短码，仅通过当前入口支持的图片附件方式提交，询问短码；再试无效文件和明确不支持该能力的模型。 | 支持时模型请求确实含图像内容且正确识别，不是读到 prompt 中的答案；无效输入/不支持能力时反馈明确，无重复请求循环。核对请求、答案与错误；清除附件副本、转换缓存和下载文件。若只能测协议，附件 UI 另记未覆盖。 |
| U29：桌面/Web/网关完整链路 / 依入口 | 每个入口单独记录：从真实 UI/获授权的测试频道发输入，观察流式结果，取消长任务，断开再连接并恢复会话，最后发一条新消息；网关另用两个测试身份验证路由。 | 消息无串线、重复执行或卡在忙碌，恢复后的持久历史与当前状态一致；取消真实停止任务。保存入口、身份到 session 的映射和事件时序。外部消息发送必须已获得用户明确授权；本轮范围不含某入口就不测试。桌面 profile、浏览器测试 profile、网关配置、附件和外部测试消息按公共规则清理。 |

这些用例与自动回归互补：界面显示“已成功”而模型没收到上下文、主 agent 代替成员执行、后台进程实际未退出等问题，都需要检查真实行为和副作用。
