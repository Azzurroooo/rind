# 干到一半，把活掰回正轨

English | [简体中文](steer-the-work.zh-CN.md)

目标：回合进行中不失控——知道什么时候能插话、什么时候该排队、什么时候该打断。

核心事实：**运行中的回合从不锁死输入框**。你随时可以打字，区别只在这份输入何时生效。

## 三种输入时机

| 你想要 | 操作 | 何时生效 |
| --- | --- | --- |
| 调整当前任务 | 直接打字，Enter | 下一次模型采样前作为 steering 送入，不取消正在跑的命令 |
| 追加下一步工作 | 打字后按 **Tab** | 当前回合结束后，作为新的一条用户消息自动开始 |
| 撤回待处理的输入 | **Alt+↑**（follow-up）、**Alt+↓**（steering） | 把排队的文本取回编辑器 |
| 把排队升级为插话 | **Alt+→** | 把待处理的 follow-up 提为 steering，提前到下一次采样前 |
| 停掉当前回合 | **Ctrl+C** | 中断模型流、执行中的工具与后续步骤；待处理输入会退回编辑器。再按一次强制收尾 |

steering 不是抢占：已经发出的命令会跑完，你的话在**下一个工具步骤之前**被看到。所以"让它停"用 Ctrl+C，"让它换方向"用 Enter，两者不要混。

## 看细节

| 操作 | 效果 |
| --- | --- |
| **Ctrl+O** | 展开/收起全部工具输出（默认只显示一行摘要和状态） |
| **Ctrl+T** | 循环切换推理强度（low → medium → high → xhigh → max） |
| **↑ / ↓** | 翻阅你发过的 prompt 历史 |
| **Esc** | 关闭当前菜单或监视器；斜杠菜单打开时先关它 |
| **?** | 打印命令列表 |

Shift+Enter 或 Ctrl+Enter 换行，写多行 prompt。

## 什么时候用哪种

- 模型越跑越偏，但方向还对：Enter 来一句 steering，比打断重来省 token。
- 你想接着干的事和当前任务无关：Tab 排队，它会在当前回合结束后自动成为下一轮。
- 命令卡死、模型跑偏：Ctrl+C。回合结束但任务没结束的话，重新描述剩余部分再发一次。
