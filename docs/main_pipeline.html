Rind Main Pipeline

frontend-cli and desktop launch the same headless Runtime Package over JSONL.

Startup

surface -> main.py app-server --stdio
        -> agent/runtime/server/app_server.py
        -> agent/bootstrap/container.py
        -> agent/runtime/core

Requests and events

Requests carry kind: request, a request_id, a method, and params. Responses reuse the request id. Events use method: session/update, monotonic sequence, durability, session/turn ids, and event.type.

Standard session and model methods are complemented by capability-gated rind/ extensions. Both product surfaces consume the same contract.

See main_pipeline.md for the source document.
