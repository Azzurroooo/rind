# 回来继续干

English | [简体中文](resume.zh-CN.md)

目标：昨天没干完的活，今天原样接着干；想换条路子试，又不破坏现有历史。

## 会话自动保存

会话按**目录**分组：`rind --session <id>` 恢复时，它会自动找到会话所在的目录。会话 ID 形如 `20260825_101530_ab12cd34`，出现在启动横幅和 `/status` 里。

```text
/sessions       列出最近的会话
/rename <name>  给当前会话起个好记的名字
/status         会话 ID、名称、模型与连接、最近一次采样用量
```

## 恢复与分叉

| 场景 | 做法 |
| --- | --- |
| 接着上次干 | `rind --session <id>` 直接恢复；启动横幅会先回放最近一次对话的片段，不会盲目接着干 |
| 查看超长对话更早的内容 | 转录默认只显示最新一段，并说明隐藏了多少更早消息；`/history` 每次加载上一页，直到整段对话都显示出来 |
| 翻找历史会话 | `/sessions` 列出近期会话，↑↓ 选择，Enter 在**另一个 CLI 窗口**打开它，当前窗口不受影响 |
| 从某个中间点另起一条路 | `/fork`，选那条消息，从它分出新会话，原历史不动 |
| 历史太长，想主动瘦身 | `/compact`，见下文 |

`/fork` 复制的是到所选消息为止的历史；运行中的任务、凭据类状态不随之复制。分叉后的两会话互不影响。注意切换会话不改写工作区文件——历史是历史，文件是文件。

## 上下文超了怎么办

长会话迟早撞上模型窗口。Rind 不删历史：

- `/context` 打开上下文面板：两页，第一页是这块会话的**组成**（系统提示、RIND.md、Skill 目录、消息……各占多少），第二页是**预算与用量**。Tab / ← / → 翻页，Esc 关闭。
- `/compact` 主动压缩：把旧历史换成一段交接摘要，最近的消息原样保留。压缩后会话可以无缝继续。

压缩替换的只是**模型视图**，磁盘上的原始记录不动，所以 `/context` 看到的"磁盘有、模型没带"是正常的。更多机制见[压缩交接](../internals/02-context/compaction-handoff.zh-CN.md)。
