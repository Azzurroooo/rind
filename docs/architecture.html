3. 一次 turn

sequenceDiagram
    autonumber
    participant Input as ChatCLI / API / stdio
    participant Runtime as AgentRuntime
    participant Store as SessionStore
    participant Runner as TurnRunner
    participant Context as ContextManager
    participant LLM as ChatClient
    participant Pump as stream_pump + MessageStreamParser
    participant Processor as ToolCallProcessor
    participant Executor as ToolExecutor
    participant Tool as Builtin Tool
    participant Output as RuntimeEvent consumer
    Input->>Runtime: initialize() / run_turn(query)
    Runtime->>Store: initialize session
    Runtime->>Runner: run_turn(session, turn_id)
    Runner-->>Output: turn_started
    loop model/tool continuation
        Runner->>Context: resolve skills + build context
        Context->>Store: read messages / metadata
        Context-->>Runner: ContextBuildResult
        Runner-->>Output: context_built / skill_activated
        alt compact or recovery required
            Runner->>Context: compact / rescue
            Context->>Store: persist compaction boundary
        end
        Runner->>LLM: stream(messages, tools)
        LLM-->>Pump: provider chunks
        Pump->>Runner: assistant_delta / tool_input_delta
        Runner-->>Output: incremental events
        alt no tools
            Runner->>Store: persist assistant message
        else tools requested
            Runner->>Processor: process_tool_calls()
            Processor->>Executor: execute_tool(call)
            Executor->>Tool: invoke
            Tool-->>Executor: ToolResult
            Executor-->>Processor: normalized result
            Processor->>Store: persist call + tool message
            Processor-->>Runner: tool_result / file_changed / question
        end
    end
    Runner->>Store: persist usage and terminal turn state
    Runner-->>Runtime: completed / failed / cancelled
    Runtime-->>Input: terminal event stream

8. frontend-cli（ts_cli 启动链）

仓库中没有独立的 ts_cli 目录；当前终端客户端是 Node ESM 的 frontend-cli/bin/rind.js。它启动 Python stdio runtime 子进程，不直接复用 Python ChatCLI。

sequenceDiagram
    autonumber
    participant Shell as Shell / npm bin
    participant Node as frontend-cli/bin/rind.js
    participant Env as runtime-env.js
    participant Py as Python child
    participant Stdio as agent.interfaces.runtime_server.stdio
    participant Boot as stdio.main / async_main
    participant Protocol as JSONL protocol
    participant UI as terminal-ui / readline
    participant Render as state + rendering
    Shell->>Node: node bin/rind.js [args]
    Node->>Node: resolve repoRoot and RIND_PYTHON
    alt help/version
        Node->>Env: buildRuntimeEnv(repoRoot)
        Node->>Py: spawnSync(python, main.py, inherit stdio)
        Py-->>Shell: output + exit code
    else interactive
        Node->>Env: buildRuntimeEnv(repoRoot)
        Node->>Py: spawn(python, -c runtimeBootstrap, cliArgs)
        Py->>Boot: runpy.run_module(stdio, __main__)
        Boot->>Boot: configure signals + UTF-8 + parse args
        Boot->>Boot: validate session + Config reload/validate
        Boot->>Stdio: build container(enable_goal=true) + run()
        Node->>Node: attach stdout line buffer, stderr and exit handlers
        Node->>Protocol: request(initialize)
        Protocol->>Stdio: JSONL request
        Stdio-->>Protocol: initialize response + capabilities
        Protocol-->>Node: sessionInfo + slash commands
        alt TTY
            Node->>UI: createTerminalUI().start()
        else non-TTY
            Node->>UI: readline + stdin data listener
        end
        Node->>Render: startupText(info) + promptLoop()
    end
文件职责
bin/rind.jsPython child、JSONL multiplex、prompt loop、事件状态、shutdown。
lib/runtime-env.jsPython path、UTF-8、环境变量。
lib/runtime-protocol.jsrequest id、event type、turn input method。
lib/*-state.jscompact、model、slash、choice、interrupt 等局部状态。
lib/terminal-ui.js / line-editor.jsTTY 动态帧和输入编辑；非 TTY 使用 readline。
lib/rendering.jsstartup、prompt、tool/status、markdown 输出。
